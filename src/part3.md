# 第 4 章 真题选析（27 题，含答案与解析）

本章 27 题全部来自 2024 下半年、2025 下半年、2026 上半年的考生回忆版真题。每题标注场次，答案与解析由编者按教材口径复核，**标“参考答案”而非“标准答案”**——回忆版题干可能与原卷有出入，遇到争议以你的教材为准。

答题建议：先盖住答案自己做一遍，把错题按“知识域”归类，再回第 3 章对应小节补漏。这比顺序刷 500 题有效得多。

## 4.1 2026 年上半年（9 题）

**1.【2026 上】千兆以太网在使用超五类/六类双绞线传输时，实际使用（ ）芯。**

A. 6　B. 4　C. 2　D. 8

**参考答案：D**

解析：1000BASE-T 用 4 对（8 芯）双绞线同时双向传输，每对 250 Mbps，靠 PAM-5 编码与回声消除实现全双工。百兆 100BASE-TX 只用 2 对（4 芯），这是最常见的干扰项。

**2.【2026 上】下列说法正确的是（ ）。**

A. BGP 路由协议属于应用层协议　B. BGP 基于 UDP 协议的 179 端口工作　C. 运行 BGP 的两台路由器 AS 号相同时，建立的邻居叫 EBGP 邻居　D. BGP 的各个区域（骨干区域、特殊区域等）必须配置 AS 号

**参考答案：A**

解析：BGP 封装在 TCP 之上（179 端口），所以是应用层协议；B 错在 UDP；同 AS 是 IBGP，异 AS 才是 EBGP；区域是 OSPF 的概念，BGP 的划分单位是 AS。

**3.【2026 上】CPU 利用（ ）来解决运算速度和内存存取速度差异过大而造成的性能瓶颈。**

A. 寄存器　B. 运算器　C. 控制器　D. 高速缓存

**参考答案：D**

解析：Cache 位于 CPU 与主存之间，缓存近期频繁访问的指令和数据，命中时不必访问主存。寄存器在 CPU 内部，容量极小，解决不了“与内存的速度差”这个整体瓶颈。

**4.【2026 上】以下关于 TCP 拥塞控制慢启动算法的描述，正确的是（ ）。**

A. 慢启动使用指数增长，当到达拥塞阈值后转为线性增长　B. 慢启动过程中，拥塞窗口不会超过拥塞阈值　C. 慢启动中拥塞窗口以固定速率增长　D. 慢启动从一个窗口值开始，窗口每经过一个 RTT 倍增

**参考答案：A**

解析：慢启动每 RTT 让 cwnd 翻倍（指数），到达 ssthresh 后进入拥塞避免，每 RTT 加 1（线性）。B 错在“不会超过”（实际会达到并越过阈值）；C 错在“固定速率”。D 只描述了前半段、没有转折关系，信息不完整——这类“两项都沾边”的题，选**覆盖全过程**的那一项。

**5.【2026 上】EPON 系统中，上下行数据采用的封装格式是（ ）。**

A. GEM 封装　B. SDH 虚容器　C. Ethernet 以太网帧　D. ATM 信元

**参考答案：C**

解析：EPON 即 Ethernet PON，上下行都以以太网帧承载，下行广播、上行 TDMA 分时发送。GEM 是 GPON 的封装；SDH 虚容器属于 SDH/MSTP；ATM 信元是 APON/BPON。三者要能一一对应。

**6.【2026 上】下列网络拓扑类型中，可靠性最高的是（ ）。**

A. 星型　B. 树型　C. 环型　D. 网状型

**参考答案：D**

解析：全网状拓扑任意一条链路故障都有备用路径，可靠性最高；代价是链路数按 n(n−1)/2 增长，成本与布线难度最大。环型靠双环或自愈环提高可靠性，仍不及网状。

**7.【2026 上】下列选项不属于 RIP 路由协议技术特点的是（ ）。**

A. 逐跳收敛　B. 使用累计链路开销作为选路依据，会考虑带宽、延迟和跳数等因素　C. 通过水平分割避免路由环路　D. 最大跳数不超过 15

**参考答案：B**

解析：RIP 是距离矢量协议，**只以跳数为度量**，完全不看带宽和时延；B 描述的是 OSPF/IS-IS 的链路开销。最大 15 跳、16 视为不可达，是 RIP 的经典特征。

**8.【2026 上】下列关于 DNS 缓存的描述中，错误的是（ ）。**

A. DNS 缓存数据库中不仅记录 RR 记录，也包含查询结果“不存在”的记录　B. DNS 协议标准要求解析器必须实现缓存从而提高查询响应速度　C. 收到用户请求后，第一个检查浏览器中的 DNS 缓存记录　D. DNS 数据可以缓存在客户端的不同位置，它的生存时间由 TTL 字段决定

**参考答案：B**

解析：缓存是优化手段，不是协议强制要求；否定缓存（NXDOMAIN）确实会被记录并受 TTL 约束；TTL 决定缓存存活时间。B 的“必须”是典型的绝对化错误。

**9.【2026 上】下列计算机系统输入输出设备中，具备双向传输能力的是（ ）。**

A. 触摸屏　B. 键盘　C. 触摸板　D. 鼠标

**参考答案：A**

解析：触摸屏同时具备显示（输出）与触控采集（输入）能力。注意“触摸板”只是输入设备，与“触摸屏”一字之差，是本题的陷阱。

## 4.2 2025 年下半年（12 题）

**10.【2025 下】路由协议的主要作用是（ ）。**

A. 实现物理地址和 IP 地址的相互转换　B. 交换网络拓扑信息，确定数据传输的最佳路径　C. 保障数据的高可靠传输　D. 将多个可网管的二层交换机连接，组成一个局域网

**参考答案：B**

解析：路由协议的本质是交换可达性/拓扑信息并计算最优路径；A 是 ARP，C 是 TCP 的职责，D 是交换机与生成树干的事。

**11.【2025 下】在交换机上将两条物理链路配置为一个链路聚合组，流量在这两条物理链路上如何实现负载均衡？（ ）**

A. 配置负载均衡策略，根据策略将流量发送到不同的物理链路　B. 配置链路优先级，流量优先发送到优先级别高的物理链路　C. 配置 MSTP 协议，设置一条链路为主、另一条为备，实现链路冗余　D. 链路聚合协议会自动协商，确保每条链路承担相同的流量

**参考答案：A**

解析：Eth-Trunk 按哈希策略（源/目的 MAC、IP、端口组合）把**流**分配到成员链路，同一条流始终走同一条链路，避免乱序。D 的“相同流量”是错的——不是均分，且逐包均分会导致乱序。

**12.【2025 下】路由器 R1 已完成如下配置，下列命令可以将接口 GE0/0/0 的 IP 10.1.1.1/24 加入 OSPF 区域 0 的是（ ）。**

~~~text
interface GigabitEthernet0/0/0
 ip address 10.1.1.1 255.255.255.0
~~~

A. §[R1-ospf-area-0.0.0.0] network 10.1.1.1 24 area 0§　B. §[R1-GigabitEthernet0/0/0] ospf enable area 0§　C. §[R1-ospf 1 area 0] ip address 10.1.1.1 255.255.255.0§　D. §[R1-ospf-1-area-0.0.0.0] import-route interface GigabitEthernet0/0/0§

**参考答案：B**

解析：华为 VRP 有两种宣告方式：区域视图下 §network 网络地址 反掩码§（注意是**反掩码**，且需在 OSPF 区域视图），或接口视图下 §ospf enable [进程号] area 区域号§。A 的格式与参数都不对；C 把接口地址命令错放进 OSPF 视图；D 的 import-route 用于引入外部路由（如直连外的静态、其他协议），不是宣告本接口。

**13.【2025 下】移动终端连接到 WLAN 中进行的第一步操作是（ ）。**

A. 识别　B. 扫描　C. 认证　D. 关联

**参考答案：B**

解析：完整流程是**扫描（主动探测或被动监听 Beacon）→ 认证 → 关联 → 安全认证（PSK/802.1X）→ DHCP 取址**。没有扫描就发现不了 SSID，后续都无从谈起。

**14.【2025 下】在交换机上划分 VLAN 是为了（ ）。**

A. 为用户自动分配 IP 地址　B. 减少数据帧冲突　C. 缩小网络的广播域　D. 简化交换机的管理

**参考答案：C**

解析：VLAN 在二层把一个大广播域切成多个小广播域，顺带提升安全性与管理灵活性。冲突域由交换机端口隔离，与 VLAN 无关；自动分配 IP 是 DHCP 的事。

**15.【2025 下】交换机端口配置如下，下列说法中正确的是（ ）。**

~~~text
interface GigabitEthernet0/0/5
 port link-type access
 port default vlan 100
 port-security enable
 port-security maxmac-num 1
~~~

A. 该端口类型配置为 access，表示仅可以接入交换机或路由器　B. 该端口启用端口安全，并配置学习到的 MAC 地址最大保存时间为 1 小时　C. 该端口收到无 VLAN 标签的数据帧会打上 VLAN 100 标签在交换机内部转发和处理　D. 该端口收到带有 VLAN 100 标签的数据帧会剥离 VLAN Tag 在交换机内部转发和处理

**参考答案：C**

解析：access 口用于接终端（A 反了）；§maxmac-num§ 是**允许学习的最大 MAC 数**，不是老化时间（B 错）；access 口收到**带标签**的帧，若标签不是本口 PVID 通常直接丢弃，不存在“剥离后在内部转发”（D 错）。C 描述的是 access 口的 PVID 行为，正确。

**16.【2025 下】交换机配置如下，下列说法正确的是（ ）。**

~~~text
interface Vlanif10
 ip address 172.16.10.1 255.255.255.0
~~~

A. 配置该交换机所有 access 接口默认为 vlan10　B. 创建逻辑接口并配置 IP 地址　C. 配置该交换机下所有接入终端的默认网关　D. 交换机收到的所有数据帧默认都转发至该逻辑接口

**参考答案：B**

解析：Vlanif 是三层逻辑接口，配 IP 后可用于 VLAN 间路由或设备管理，它是该 VLAN 的**网关候选**，但不会自动给终端下发网关（那要靠 DHCP 选项），也不会把“所有帧”都送过来。

**17.【2025 下】某公司 WEB 服务器经常被攻击者利用未修复的 Struts2 漏洞发起远程攻击，可以通过部署（ ）设备有效阻断该类攻击。**

A. WEB 防火墙　B. 防火墙　C. 漏洞扫描系统　D. 入侵防御系统

**参考答案：A**

解析：Struts2 漏洞利用发生在 HTTP 应用层，WAF 能解析 HTTP 报文并按规则/虚拟补丁拦截；普通防火墙只看五元组；漏扫只发现不阻断；IPS 虽可串接阻断，但对 Web 业务语义的针对性远不如 WAF，本题标准答案取 A。

**18.【2025 下】下列关于 SNMP 的描述正确的是（ ）。**

A. SNMPv3 通过 TLS 协议实现端到端加密，防止数据被窃听　B. SNMP 系统由 NMS 和 MIB 两部分组成　C. SNMPv2c 引入 GetBulk 操作，实现高效块检索　D. SNMPv1 基于团体名认证，安全性比较高

**参考答案：C**

解析：v3 用的是 USM（基于用户的安全模型）而非 TLS（A 错）；SNMP 由 NMS、Agent、MIB 三部分组成（B 少一个）；v1 的团体名明文传输，安全性低（D 错）。

**19.【2025 下】某企业搭建办公区域网络，最长布线距离不超过 50 米，要求千兆带宽且成本低，以下传输介质最符合需求的是（ ）。**

A. 多模光纤　B. 双绞线　C. 单模光纤　D. 同轴电缆

**参考答案：B**

解析：50 m 远小于双绞线 100 m 的千兆传输上限，Cat5e/Cat6 即可满足且成本最低。光纤在大距离场景才体现优势；同轴已基本退出局域网。

**20.【2025 下】OSPF 路由协议中的 Hello 报文的主要作用是（ ）。**

A. 邻居之间交换链路状态信息　B. 向邻居路由器传递路由，更新路由表　C. 发现邻居并维护邻居关系　D. 用于 ABR 和 ASBR 路由器的选举

**参考答案：C**

解析：Hello 负责发现邻居、协商参数、选举 DR/BDR、维持保活；交换链路状态的是 LSA（封装在 LSU 中）；ABR/ASBR 不是选举出来的，而是由所处区域和是否引入外部路由决定。

**21.【2025 下】OSPF 路由协议中，采用多区域（Area）设计的主要目的是（ ）。**

A. 每个区域可以采用不同的路由协议，提升灵活性　B. 限制 LSA 的泛洪范围，降低 SPF 计算开销，提升网络的可扩展性　C. 多骨干区域设计可以提高网络冗余　D. 实现不同自治系统之间的路由控制和隔离，简化路由表

**参考答案：B**

解析：OSPF 要求所有非骨干区域必须与 Area 0 相连，且只有一个骨干区域（C 错）；区域内外仍是同一个 AS（D 错）；同一个 OSPF 进程只能跑 OSPF（A 错）。多区域的价值就是**把拓扑变化的影响限制在区域内部**。

**22.【2025 下】用户希望在手机、电脑和平板等多个终端上实时同步看到一致的邮件状态（包括已读、未读和归档等），邮件客户端应配置（ ）协议接收邮件。**

A. POP3　B. HTTP　C. IMAP　D. SMTP

**参考答案：C**

解析：IMAP 把邮件保存在服务器上并同步状态（已读/未读/文件夹），天然支持多终端一致；POP3 默认下载到本地并删除服务器副本，多终端之间状态不同步；SMTP 只负责发送。

**23.【2025 下】用户在本地计算机上用 DNS 查询命令时发现，使用服务器名可以查询到 IP 地址，但反之失败，可能的原因是 DNS 服务器（ ）。**

A. A 记录为空　B. 宕机　C. PTR 记录为空　D. MX 记录为空

**参考答案：C**

解析：正向解析靠 A/AAAA 记录，反向解析靠 PTR 记录。正向成功说明服务器工作正常（排除 B）；反向失败说明 PTR 缺失。MX 只影响邮件路由。

> **争议题提醒：IPv6 的 Next Header 字段**
>
> 2025 下半年考了这样一题：“IPv6 报文首部中 Next Header 字段的作用是”。选项是 A 描述服务类型、B 描述扩展首部类型、C 描述 Payload 协议类型、D 描述报文首部的下一个字段。
>
> 教材的准确表述是：Next Header 标识**紧跟在基本首部之后的内容类型**——有扩展首部时指向第一个扩展首部，无扩展首部时指向负载（上层）协议。所以 B 和 C 各对一半，机构给出的答案是 **C**。
>
> 这类题的启示是：遇到“半对半错”的选项，按**最常见场景**（无扩展首部的普通数据包）取答案，同时在心里记住完整表述，下午的简答题可以写全。

## 4.3 2024 年下半年（6 题）

**24.【2024 下】下列关于交换机堆叠的说法正确的是（ ）。**

A. Master 交换机故障后，Slave 交换机中优先级值最大的会被选举为 Master，承担控制层面功能　B. 堆叠就是将多台交换机相互级联　C. Master 交换机和 Backup、Slave 交换机共同承担数据转发　D. 必须使用专用堆叠卡和堆叠线缆

**参考答案：C**

解析：堆叠后多台设备在逻辑上是一台，**所有成员都参与数据转发**，控制平面由 Master 承担；Master 故障后由 **Backup** 接管，而不是在 Slave 中重新选优先级最大的（A 错）；堆叠可用专用堆叠卡，也可用普通业务口（D 的“必须”错）；级联只是简单的端口互连，不是堆叠（B 错）。

**25.【2024 下】VLAN 技术所依据的协议是（ ）。**

A. IEEE 802.15　B. IEEE 802.3　C. IEEE 802.11　D. IEEE 802.1Q

**参考答案：D**

解析：802.1Q 定义了 VLAN 标签格式（4 字节，含 12 位 VLAN ID）；802.3 是以太网，802.11 是无线局域网，802.15 是无线个人网（蓝牙、ZigBee）。

**26.【2024 下】静态路由的缺点是（ ）。**

A. 路由收敛慢　B. 不能灵活适应网络结构的变化　C. 不支持 IPv6　D. 必须运行路由协议才能生成路由表

**参考答案：B**

解析：静态路由由手工配置，拓扑一变就要人工改，**不灵活**；但它没有“收敛”概念（收敛是动态协议的事，A 不对），静态路由同样支持 IPv6，配置静态路由恰恰不需要运行动态协议（D 反了）。

**27.【2024 下】当 IP 报文在网络中传输时，如果其生存时间（TTL）减至 0，将会发送的 ICMP 消息是（ ）。**

A. Parameter Problem　B. TTL Exceeded　C. Source Quench　D. Destination Unreachable

**参考答案：B**

解析：TTL 减为 0 时路由器丢弃报文并回送 ICMP 超时报文（Type 11，Time Exceeded，题面写作 TTL Exceeded）。tracert 正是利用这一机制逐跳探测。Parameter Problem 对应首部字段错误，Source Quench 已废弃。

## 4.4 本章怎么用

- 27 题里，**读配置判断作用**的题有 4 道（12、15、16、24），这正是近三年增长最快的题型。练法：把第 5 章的配置模板遮住解释，逐行口述每条命令的作用。
- **协议对比型**的题有 9 道（2、7、10、11、18、20、21、22、25），错的根本原因几乎都是“记混了度量/封装/端口”。建议做一张自己的三列对照表（协议—度量—封装/端口），考前只看这张表。
- **概念辨析型**的题有 8 道（3、4、8、9、14、23、26、27），考的是“两个都沾边时选更完整的那个”。这类题没有捷径，只能靠把定义读到能复述。
